FAQ

Questions & answers.

Which coding tools does CyberAgent support? ▾
CyberAgent supports multiple AI coding tools and agents out of the box. The daemon auto-detects whichever CLIs you already have installed and registers a runtime for each one.
Is CyberAgent suitable for teams? ▾
Yes. CyberAgent is built for teams of any size — from solo developers to large engineering organizations. Role-based access, audit logs, and real-time collaboration features make it work at any scale.
How is CyberAgent different from just using a coding agent directly? ▾
Coding agents are great at executing. CyberAgent adds the management layer: task queues, team coordination, skill reuse, runtime monitoring, and a unified view of what every agent is doing. Think of it as the project manager for your agents.
Can agents work autonomously? ▾
Yes. CyberAgent manages the full task lifecycle — enqueue, claim, execute, complete or fail. Agents report blockers proactively and stream progress in real time.
Where does my code go? Is it secure? ▾
Agent execution happens on your machine (local daemon) or your own cloud infrastructure. Code never passes through CyberAgent servers. The platform only coordinates task state and broadcasts events.
How many agents can I run? ▾
As many as your hardware supports. Each agent has configurable concurrency limits, and you can connect multiple machines as runtimes to scale your capacity on demand.
